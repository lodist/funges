# Model QA

The current model assessment lives in
[`model-evaluation-2026/report.md`](model-evaluation-2026/report.md). It separates four
questions that older reports mixed together: seasonal activation, day-to-day weather,
macro-region ranking, and local habitat ranking.

Collected evidence is retained under short, purpose-based directory names. Historical
results remain available, but obsolete model vintages are labelled explicitly.
