## Available Components

- **Button** - Versatile button component with multiple variants
  - Variants: primary, secondary, outline, enhanced-outline, ghost, link, destructive
  - Sizes: small, medium, large
  - States: disabled, loading, with icon

### Button Variants

- **default**: Primary button with brand color background
- **secondary**: Secondary button with subtle background
- **outline**: Button with border and card background (improved contrast)
- **enhanced-outline**: High-contrast outline button with primary border and white background
- **ghost**: Transparent button with hover effects
- **link**: Text-only button that looks like a link
- **destructive**: Button for dangerous actions (red theme)

### Recent Improvements

**Enhanced Contrast for Outline Buttons**:

- The `outline` variant now uses `bg-card` instead of `bg-background` for better contrast
- Added new `enhanced-outline` variant with high contrast for important actions
- Improved visibility of buttons on light backgrounds
